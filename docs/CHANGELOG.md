# Changelog

All notable changes to the GitHub Integration extension.

## [1.0.0] - 2025-01-01

### Added
- Initial release
- GitHub App authentication
- Bi-directional issue synchronization
- Pull request tracking and linking
- Commit auto-linking via issue keys in commit messages
- PR review status synchronization
- Check suite and check run tracking
- Webhook processing for real-time updates
- Custom data storage for PR metrics
- Commands: syncRepository, linkPR, createIssue, viewPR, exportMetrics
